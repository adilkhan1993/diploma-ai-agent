# Описание проекта: Market Intelligence Agent

## 1. Описание проблемы (Problem Statement)
В современном бизнесе аналитики, маркетологи и менеджеры продуктов сталкиваются с огромным потоком неструктурированной информации. Для проведения анализа конкурентов или изучения рынка специалисту приходится:
1. Вручную открывать десятки веб-страниц и вычитывать длинные статьи.
2. Изучать объемные многостраничные PDF-отчеты (исследования рынка, финансовые сводки).
3. Тратить часы на синтез этой информации в короткую выжимку.

**Суть проблемы:** Ручной сбор и первичный анализ сырых данных отнимает до 70% времени специалиста, оставляя меньше ресурсов на принятие стратегических решений.

## 2. Целевой пользователь (Target Audience)
Продукт спроектирован для:
* **Маркетологов и продуктовых аналитиков**, которым нужно быстро вытащить главное из статей о конкурентах.
* **Инвесторов и бизнес-консультантов**, которым необходимо проанализировать длинный PDF-отчет и задать по нему вопросы.
* **Студентов и исследователей**, работающих с большими объемами текстовой информации и научных публикаций в интернете.

## 3. Решение
Market Intelligence Agent — это автономный ИИ-помощник, который берет рутину на себя. Пользователю достаточно отправить агенту URL-ссылку на статью или загрузить PDF-файл, и агент самостоятельно применит нужные инструменты (Tools) для извлечения текста, его анализа и выдачи готового структурированного ответа в режиме диалога.

## 4. Обоснование выбора стека технологий (Tech Stack Justification)

Для реализации проекта был выбран современный стек, обеспечивающий высокую производительность и масштабируемость:

* **Frontend: Next.js + Tailwind CSS**
  * *Почему:* Next.js обеспечивает отличную производительность (SSR/SSG), легко интегрируется с Vercel для деплоя и идеально подходит для создания быстрых React-интерфейсов. Tailwind CSS позволяет стилизовать компоненты (например, интерфейс чата) максимально быстро.
* **Backend: Python + FastAPI**
  * *Почему:* FastAPI работает асинхронно из коробки, что критически важно для реализации потоковой передачи данных (Streaming API) от языковой модели к клиенту. Python имеет лучшую экосистему для AI (LangChain, LangGraph).
* **AI Engine: LangGraph + Llama 3.1 (Groq API)**
  * *Почему LangGraph:* Позволяет строить сложную логику автономного агента, способного самостоятельно выбирать инструменты (RAG для PDF или Web Scraper для ссылок) и сохранять состояние (память) диалога.
  * *Почему Groq / Llama 3.1:* Llama 3.1 обеспечивает качество рассуждений на уровне топовых моделей, а использование LPU (Language Processing Units) от Groq дает феноменальную скорость генерации токенов, что делает Streaming-ответы практически мгновенными.
* **Инфраструктура: Docker + Render**
  * *Почему:* Docker контейнеризирует приложение, исключая проблему "работает только на моем компьютере", а Render позволяет легко и бесплатно разворачивать Docker-контейнеры в облаке.

# Проект: AI-Аналитик конкурентов (Market Intelligence Agent)

## 1. Проблема (в одном предложении)
Приложение автоматизирует процесс конкурентного анализа: агент самостоятельно ищет конкурентов по заданному запросу, парсит их сайты, анализирует цены и предложения, и формирует итоговый структурированный отчет, экономя часы ручной работы.

## 2. Целевой пользователь и текущее решение
* **Целевая аудитория:** Предприниматели, product-менеджеры, маркетологи, стартаперы.
* **Как решают сейчас:** Вручную ищут компании в Google, открывают десятки вкладок, выписывают цены и фичи в таблицы Excel, вручную ищут отзывы на сторонних площадках. Это долгий, рутинный и подверженный человеческому фактору процесс.

## 3. Архитектура системы
* **Пользователь** отправляет запрос (например, "Сравни сервисы доставки еды в Алматы") через веб-интерфейс.
* **Фронтенд (Next.js)** принимает запрос и по HTTP (с поддержкой Streaming) отправляет его на бэкенд.
* **Бэкенд (FastAPI)** принимает запрос и передает его автономному агенту.
* **Агент (LangGraph/LangChain)** анализирует запрос и решает, какие инструменты использовать.
* **Инструменты (Tools):**
  1. `WebSearchTool` — поиск в интернете (Tavily API или DuckDuckGo) для нахождения списка конкурентов и упоминаний.
  2. `WebScraperTool` — кастомный парсер (BeautifulSoup/Playwright) для извлечения текста непосредственно с сайтов конкурентов.
* **LLM** обрабатывает собранные данные и возвращает структурированный ответ пользователю.

## 4. Выбранный стек технологий
* **Фреймворк агента:** LangChain + LangGraph (для реализации сложной агентной логики и циклов).
* **Модель:** OpenAI GPT-4o-mini (или аналогичная быстрая и экономичная модель).
* **Бэкенд:** Python, FastAPI (с валидацией Pydantic и стримингом).
* **Фронтенд:** Next.js, React, Tailwind CSS.
* **Деплой:** Docker, Vercel (фронтенд), Railway/Render (бэкенд).
